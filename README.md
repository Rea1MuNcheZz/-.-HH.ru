# Анализ резюме с HeadHunter

Учебный проект по курсу «Python для анализа данных»: разведывательный анализ (EDA) резюме с hh.ru — от преобразования «сырых» текстовых признаков до очистки данных от дубликатов, пропусков и выбросов.
Ссылка на исходный датасет: https://drive.google.com/file/d/1Kb78mAWYKcYlellTGhIjPI-bCcKbGuTn/view
## Данные

- **Датасет:** `dst-3.0_16_1_hh_database.csv` (~450 МБ, разделитель `;`)
- Файл не хранится в репозитории (ограничение GitHub — 25 МБ), он добавлен в `.gitignore`.
- Положите скачанный файл в папку `data/`. Там же должен лежать `ExchangeRates.csv` (курсы валют для перевода зарплат в рубли).

## Структура репозитория

```
├── hh_resume_analysis.ipynb   # основной ноутбук с анализом
├── figures/                   # интерактивные Plotly-графики в HTML
├── data/                      # сюда кладём датасет (не коммитится)
├── .gitignore
└── README.md
```

## Что сделано

1. **Исследование структуры данных** — чтение, `info`, пропуски, статистика.
2. **Преобразование признаков** — из текстовых столбцов выделены: образование, пол, возраст, опыт работы (в месяцах), город, готовность к переезду и командировкам, типы занятости и графика, желаемая зарплата в рублях (по курсу на дату обновления резюме).
3. **Исследование зависимостей** — распределения, зависимость зарплаты от образования, города, готовности к переезду/командировкам, тепловые карты, сопоставление опыта и возраста.
4. **Очистка данных** — удаление дубликатов и пропусков, ручная и статистическая (правило трёх сигм на логарифмической шкале) фильтрация выбросов.

## Основные выводы

- Возраст соискателей: мода — 30 лет, основная масса — примерно 24–33 года.
- Желаемая зарплата: медиана ≈ 59 тыс. руб., распределение с сильной правосторонней асимметрией и экстремальными выбросами.
- Чем выше уровень образования, тем выше медианная желаемая зарплата.
- Самые высокие ожидания — в Москве, затем в Санкт-Петербурге; в остальных городах ниже.
- Готовность к командировкам связана с более высокой желаемой зарплатой.
